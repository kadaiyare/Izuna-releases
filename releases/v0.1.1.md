# Izuna v0.1.1 Beta

Android 16（API 36）以降、ARM64／x86_64向けの公開Betaです。

## 変更点

- 設定画面のリポジトリリンクとDiscord Rich PresenceのGitHubボタンを公開先Izuna-releasesへ変更
- MusicBrainzとLRCLIBへ送るUser-Agentの連絡先も公開先へ統一
- 同じ配布署名を維持し、versionCodeを3へ更新
- 公開リポジトリにアプリ・テスト・ビルド設定のソースを公開

## 導入と更新

[公開リポジトリ](https://github.com/kadaiyare/Izuna-releases)のReleaseからIzuna-0.1.1.apkを取得してください。同じ配布署名のv0.1.0から上書き更新できます。開発用debug版とは署名が異なり、自動データ移行はありません。アンインストールすると履歴・プレイリスト・設定などが失われます。

キュー復元は初期状態オン、履歴記録・オンライン取得・外部共有・Scrobble送信は初期状態オフです。更新時は保存済みの設定を維持します。送信情報は[プライバシー](https://github.com/kadaiyare/Izuna-releases/blob/main/PRIVACY.md)を参照してください。

## 既知の制限

- Discord終了・通信断後に古い活動表示が残る場合があります
- Discord Social SDK 1.10.19337の厳密な16 KB RELRO終端検査は未通過です。4 KB ARM64実機と16 KB x86_64仮想端末の確認は、16 KB ARM64実機での確認を意味しません
- ListenBrainz互換APIは模擬応答で検証しており、実サーバーの受付確認は未実施です
- Last.fmは配布版で未設定です。EQ・左右バランス・Convolutionは含めません
- 公開カバー・歌詞は外部カタログと通信状態に依存します。品質表示は音源の情報で、実出力形式の測定ではありません

詳しくは[既知の制限](https://github.com/kadaiyare/Izuna-releases/blob/main/KNOWN_ISSUES.md)を参照してください。

## 配布と検査

GitHub Actionsで専用配布鍵を用いて署名し、単体テスト・lint・依存照会・SDK・ソース・APK・証明書の検査を実行します。APKにチェックサム、公開証明書のハッシュ、依存一覧、検査JSON、プライバシー、リリースノートを添付します。

passed=trueは定義した配布検査の成功を表し、SDKの厳密な16 KB検査合格や未知の脆弱性の不在を意味しません。SDKのstrict_16kb_passed=falseと既知の不一致を開示しています。SDK単体、鍵、ローカル設定、端末データは公開しません。
