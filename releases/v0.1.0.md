# Izuna v0.1.0 Beta

Android 16（API 36）以降、ARM64／x86_64向けの初回公開Betaです。APKのアプリ内バージョン表示は0.1.0です。

## 主な機能

- 端末内FLACの再生、キュー・位置の復元、プレイリスト、任意の履歴記録・全件消去
- アルバム初期タブ、名前順のアルバム・アーティスト、アーティスト内のアルバム選択
- 背景再生と通知、再生ウィジェット、音源情報、LRCLIB同期歌詞
- Discord Rich Presenceと表示設定、公開カバー検索、ListenBrainz互換HTTPSサーバーへの送信

履歴記録・外部共有・オンライン取得は初期状態オフです。音源・埋め込み画像をアップロードしません。送信情報と削除方法は[プライバシー](https://github.com/kadaiyare/Izuna-releases/blob/main/PRIVACY.md)を参照してください。

## 導入と更新

Izuna-0.1.0.apkをダウンロードしてAndroidからインストールしてください。同じ配布署名の版は上書きできます。開発用debug版とは署名が異なり、自動移行はありません。アンインストールすると履歴・プレイリスト・設定などが失われます。

## 既知の制限

- Discord停止・通信断後に古い活動表示が残る場合があります
- 同梱SDK 1.10.19337は16 KB RELRO終端の静的検査が未通過です。4 KB ARM64実機と16 KB x86_64仮想端末の確認は、16 KB ARM64実機の確認を意味しません
- ListenBrainzの実サーバー受付は未確認です。歌詞・カバーはカタログと通信状態に依存します
- Last.fm連携、EQ・左右バランス・Convolutionはこの版では利用できません
- APK内の設定・DiscordボタンのGitHubリンクは旧開発リポジトリを指します。配布・報告にはこの公開リポジトリを利用してください

[既知の制限](https://github.com/kadaiyare/Izuna-releases/blob/main/KNOWN_ISSUES.md)に検証範囲を記載しています。
