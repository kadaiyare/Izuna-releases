# Discordの共有

同じ端末の公式Discordへログインし、Izunaの設定 → 外部連携 →「Discordで曲情報を共有」をオンにします。初期状態はオフです。TITLEとARTISTタグのあるFLACを再生すると曲情報をプロフィールへ共有します。

再生・再開・再生中のシーク・曲変更で更新し、一時停止・停止・共有オフでは消去を要求します。タグが欠けた曲は共有しません。SDKや通信の失敗でも音楽再生は続けられます。

## 表示設定

| 項目 | 選択肢 | 初期値 |
| --- | --- | --- |
| タイトル行 | 曲名／曲名 · アーティスト／アーティスト · 曲名 | 曲名 |
| アルバム名 | アーティストの横にアルバム名を追加 | オフ |
| 1行表示 | Izuna／曲のタイトル行 | Izuna |

設定 → 外部連携 →「Discordの表示設定」から変更します。プレビューは概略表示で、実際のレイアウトはDiscordの版と画面に依存します。表示設定の変更だけで共有がオンになることはありません。

## GitHubボタン

カスタムボタンは他のユーザーから見たプロフィールに表示され、自分の表示では確認できません。v0.1.1のボタンが開く公開先は[Izuna-releases](https://github.com/kadaiyare/Izuna-releases)です。

## 公開カバー

「Discordで公開カバーを表示（試験）」は別設定で、初期状態オフです。共有オン・公開カバーオン・再生中のときに曲名・アーティスト・アルバム名・任意のアルバムアーティストをMusicBrainzへ送り、Cover Art Archive／Internet Archiveで公開カバーURLを探します。Discordが公開画像を取得し、端末内の画像はアップロードしません。

タグの不一致・画像なし・通信失敗では画像なしで共有します。盤の版まで特定する方式ではなく、埋め込みジャケットと異なる場合があります。

## 注意点

Discord終了・通信断を含む操作後、共有オフでも古い表示が残る場合があります。SDKの応答だけでは消去の完了を保証できません。また同梱SDKには16 KB静的検査未通過の項目があります。[既知の制限](../KNOWN_ISSUES.md)・[プライバシー](../PRIVACY.md)を参照してください。
