# Izunaの使い方

## 曲を読み込む

Android 16以降の端末へFLACを保存し、Izunaで音楽へのアクセスを許可します。設定の「再スキャン」で一覧を更新できます。AndroidのMediaStoreに未登録のファイルは一覧に出ません。FilesなどでMusicフォルダへの配置を確認し、登録後に再スキャンしてください。ファイル選択による手動追加は未対応です。

## ライブラリと再生

アルバムが初期タブです。曲・アルバム・アーティスト・プレイリストへタップまたは左右スワイプで移動します。アーティストを開くとアルバムボタンが並び、アルバムを選ぶと曲一覧を表示します。アルバム・アーティストは名前順、アルバムの曲はディスク番号・曲番号順です。設定からARTIST／ALBUMARTISTの分類を選べます。

曲を選ぶと表示中の曲一覧をキューにして再生します。ミニプレイヤーから再生画面を開き、再生／一時停止、前後曲、シーク、シャッフル、リピートを操作できます。アルバム詳細の「ループ」、または再生画面の「このアルバムをループ」で、そのアルバムだけを繰り返せます。

再生中は画面を閉じてもバックグラウンド再生を継続し、通知やロック画面から操作できます。Androidでアプリを強制停止すると再生も停止します。

## キュー・履歴・復元

再生画面を右へスワイプすると、過去の履歴・現在曲・次のキューを表示します。上へスクロールして履歴を追加表示できます。表示対象は直近100件で、履歴の曲を選ぶとその1曲のキューに切り替えます。

キュー復元は初期状態オンです。キュー・選択曲・位置・再生モードを端末内へ保存し、起動時は一時停止状態で復元します。見つからなくなった曲は除きます。強制終了では最後に保存できた位置へ戻り、シャッフル順は再生成します。10,000曲を超えるキューは永続保存しません。

履歴記録は初期状態オフです。設定でオンにすると実際に再生していた時間だけを記録し、一時停止・読み込み待ち・シークで飛ばした時間は加算しません。オフにしても保存済み履歴は残ります。

「再生履歴を消去」は確認後に端末内の全履歴を削除します。音楽ファイル・プレイリスト・再生キュー・外部連携の送信待ちは保持します。記録がオンなら消去後から新しい履歴を作ります。

## プレイリスト

プレイリストタブで作成・名前変更・削除、曲の追加・削除ができます。プレイリストの削除で音楽ファイルは消えません。見つからなくなった曲は一覧に残し、再生には利用可能な曲だけを使います。並べ替えとインポート／エクスポートは未対応です。

## 歌詞と外部連携

再生画面を左へスワイプすると歌詞を開きます。取得を有効にするとLRCLIBへ曲情報を送り、取得済み歌詞はオフラインでも表示できます。[既知の制限](../KNOWN_ISSUES.md)を参照してください。

Discord共有、公開カバー検索、ListenBrainz送信はそれぞれ設定を有効にします。初期状態では外部共有・オンライン取得を行いません。送信内容は[プライバシー](../PRIVACY.md)、接続手順は[Discord](discord.md)・[ListenBrainz](listenbrainz.md)を参照してください。

## ウィジェットと音源情報

設定 → ホーム画面 →「再生ウィジェットを追加」から追加します。非対応のランチャーではホーム画面のウィジェット一覧からIzunaを選びます。基本サイズは4×2で、前曲・再生／一時停止・次曲を操作できます。曲名や画像のタップでアプリを開きます。

再生画面の音源情報をタップするとFLACの詳細を表示します。ビット深度やサンプルレートはファイルの情報で、DAC・Bluetoothの出力やビットパーフェクト再生を保証する表示ではありません。

## データの扱い

履歴・プレイリスト・設定・取得済み歌詞などは端末内に保存し、クラウドバックアップや端末間転送から除外しています。アンインストールやアプリのストレージ消去で失われます。アプリ内データの書き出し・移行機能はありません。更新と署名の注意は[README](../README.md)を参照してください。
